Architecture:

Install via PowerShell (downloads and extracts the binary):

PS> Invoke-WebRequest -Uri https://github.com/Isu-Ismail/ctrlv/releases/latest/download/ctrlv-cli_windows_amd64.zip -OutFile ctrlv.zip; Expand-Archive ctrlv.zip -DestinationPath C:\ctrlv
Download Portable ZIP (x64)

Configure PATH Environment Variable:

PS> [System.Environment]::SetEnvironmentVariable("PATH", [System.Environment]::GetEnvironmentVariable("PATH", "User") + ";C:\ctrlv", "User")

Install the Debian package via apt:

$ wget https://github.com/Isu-Ismail/ctrlv/releases/latest/download/ctrlv-cli_linux_amd64.deb && sudo apt install ./ctrlv-cli_linux_amd64.deb
Download .deb (x64) Download .rpm (x64)

Manual PATH Configuration (if unpacking tarball manually):

$ echo 'export PATH="$PATH:/path/to/ctrlv-folder"' >> ~/.bashrc

Install via curl & unpack to your bin folder:

$ curl -sSfL https://github.com/Isu-Ismail/ctrlv/releases/latest/download/ctrlv-cli_darwin_amd64.tar.gz | tar -xz && sudo mv ctrlv /usr/local/bin/
Download tar.gz (Intel)

Manual PATH Configuration (if not using /usr/local/bin):

$ echo 'export PATH="$PATH:/path/to/ctrlv-folder"' >> ~/.zshrc
